# Forma 서비스 기획서

## 서비스 목적

Forma는 식사·운동·체중을 기록하고, 사용자가 생활 속에서 실천할 수 있는 건강 습관을 관리하도록 돕는 반응형 웰니스 웹 서비스입니다. 의료 진단이나 치료를 제공하지 않습니다.

## 타겟 사용자

- 식사와 운동 습관을 간단히 기록하고 싶은 성인
- 본인의 음식 선호와 제외 식품을 반영한 식단 아이디어가 필요한 사용자
- 건강 정보를 한 화면에서 확인하고 싶은 개인 사용자

## 페이지와 메뉴 구성

단일 페이지의 네 개 섹션으로 구성되며 상단/측면 메뉴로 이동합니다.

1. **대시보드**: 체중 그래프, 오늘의 섭취량, 운동 요약, 기록 습관 캘린더
2. **식단 관리**: 식사 기록, 일일 섭취량, Groq 기반 7일 식단 아이디어
3. **운동 관리**: 운동 기록, 주간 운동 요약, 기본 운동 계획
4. **건강 리포트**: 최근 체중·식사·운동 기록 요약

모바일 화면에서는 사이드 내비게이션과 카드 그리드가 좁은 화면에 맞게 재배치됩니다.

## 핵심 기능

- 브라우저 로컬 저장소에 체중, 식사, 운동 기록 저장
- 목표, 알레르기·제외 식품, 음식 선호를 입력해 7일 식단 생성 요청
- Groq 응답을 날짜별 아침·점심·저녁 카드와 장보기 목록으로 표시
- Groq 응답을 기다리는 동안 기본 7일 예시를 즉시 표시
- API 키는 서버 환경 변수에서만 읽고 브라우저로 보내지 않음

## AI 기능 명세

### 입력

- 식단 목표
- 알레르기 또는 피해야 할 음식
- 좋아하거나 싫어하는 음식
- 외부 AI 전송 확인 체크박스

### 출력

- 7일의 아침·점심·저녁 메뉴
- 각 메뉴의 대략적인 1인분 양
- 장보기 재료 목록

### 실패 처리 기준

- 생성 요청 직후 기본 7일 예시를 화면에 표시해 빈 결과 화면을 방지합니다.
- Groq 응답이 오면 기본 예시를 AI 응답으로 교체합니다.
- API 키 누락, 요청 한도 초과, API 오류, 시간 초과 시 화면에 상태를 표시하고 기본 예시를 유지합니다.
- 알레르기 성분 검증을 보장하지 않으므로 사용자가 제품 표시를 확인하도록 안내합니다.

## 데이터 및 안전

- 앱의 기록 데이터는 브라우저 로컬 저장소에 둡니다.
- 식단 생성 입력값은 동의 후 Groq API로 전송합니다.
- 응답은 일반적인 식생활 아이디어이며 의료 조언이나 처방을 대신하지 않습니다.
- 서버에는 API 키를 환경 변수로 설정하고 저장소에 키를 커밋하지 않습니다.
